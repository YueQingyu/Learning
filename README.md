### 论文 1：《Cell-type deconvolution methods for spatial transcriptomics》

- 研究问题：空间转录组反卷积方法繁多混乱，缺少系统分类、对比、选型指南，多模态整合、验证、下游分析不清晰
- 方法概述：回归、降维、贝叶斯、最优传输、深度学习；整合 scRNA、图像、空间坐标；交互式方法选型表
- 创新点：首次系统梳理全部反卷积方法；统一分类框架；给可交互工具表；明确多模态融合策略
- 实验设置：这是一篇综述论文，基于已发表20 + 种反卷积方法进行归纳、对比、分类；引用多篇基准测试论文（Cell2location、RCTD、CARD 等性能对比）；用模拟伪 spot、真实组织数据作为验证依据
- 主要结论：有参考方法稳定但易传偏差；无参考可发现新细胞但注释困难；融合空间坐标与 H&E 图像可显著提升反卷积精度；反卷积输出以细胞比例为主，需用成分数据分析（CoDA）处理；未来方向：无参考算法、多样本整合、多组学融合、超高分辨率适配
- 我没有理解的地方：最优传输与贝叶斯方法在细胞映射上的核心区别；多模态融合（图像 + 转录组）的计算流程
- 这篇论文是否影响了我的兴趣判断：让我明确空间转录组反卷积的核心价值与应用场景，对其实际意义与应用产生了兴趣

### 论文 2：《A comprehensive benchmarking with practical guidelines for cellular deconvolution of spatial transcriptomics》

- 研究问题：对18 种空间转录组细胞反卷积方法做了全面基准测试，用50 个模拟 + 真实数据集，从准确性、稳健性、易用性三大维度评估，最终给出方法选择的决策树指南
- 方法概述： 纳入18 种主流反卷积方法；从准确性、稳健性、易用性三维度评估；构建决策树式方法选择指南
- 创新点：首次同时测评有 / 无单细胞参考两类方法；首次用多技术、多分辨率、多数据规模做系统性稳健性测试；首创决策树式场景化选择指南，降低工具使用门槛
- 实验设置：测评方法：18 种（分概率、NMF、图、深度学习、最优传输）；评估指标：RMSE、JSD、PCC；稳健性测试：基因数、斑点数、分辨率、细胞类型数、超参数、归一化方法
- 主要结论：CARD、Cell2location、Tangram综合性能最优；有参考方法整体优于无参考方法；数据规模越大，多数方法效果越好；平台效应与高丢失率是主要瓶颈
- 我没有理解的地方：无参考方法中主题与细胞类型如何自动匹配
- 这篇论文是否影响了我的兴趣判断：让我明确空间转录组反卷积的研究价值、应用场景与未来方向

### 论文 3：《BERT: Pre-training of Deep Bidirectional Transformers forLanguage Understanding》

- 研究问题：传统预训练模型（GPT/ELMo）为单向或浅双向，无法充分利用上下文；缺乏能同时适配句子级与词级任务的统一预训练框架 
- 方法概述： 基于双向 Transformer 编码器；统一架构，仅加输出层即可微调适配各类任务
- 创新点：首次提出深度双向预训练，打破单向语言模型限制；用 MLM 实现全层上下文融合，优于拼接式双向
- 实验设置：模型：BERTBASE、BERTLARGE；数据：BooksCorpus+Wikipedia（33 亿词）；指标：Accuracy、F1、EM；训练：TPU 预训练，GPU/TPU 快速微调
- 主要结论：深度双向显著优于单向 / 浅双向模型；MLM+NSP 联合预训练效果最好；模型越大效果越好，小数据集也受益；
- 我没有理解的地方：MLM 混合掩码策略的数学依据；NSP 任务对不同下游任务的影响机制
- 这篇论文是否影响了我的兴趣判断：帮助我理解了预训练语言模型的核心原理，明确 NLP 从任务定制走向通用预训练的趋势

请说明你对以下内容的理解：

- 卷积层的计算机制：卷积层通过一个可学习的卷积核在输入图像上滑动，在每个位置执行对应元素相乘后求和的操作，得到输出特征图的一个像素值。选择卷积核大小，在输入图像上，从左上角开始，按步长滑动，每个位置，取出与卷积核同样大小的图像块。将图像块与卷积核逐元素相乘，然后求和，得到一个数值，这个数值就是输出特征图对应位置的值。
- LSTM 的门控机制：通过遗忘门、输入门、输出门三个可学习的权重矩阵，在每个时间步对拼接后的历史隐藏状态和当前输入执行线性变换加 sigmoid 激活，得到 0-1 门控值，分别控制细胞状态的遗忘、写入和输出，从而实现对序列信息的精准调控。
- Attention 的计算过程：通过可学习的线性变换将输入映射为查询（Q）、键（K）、值（V）三个矩阵，在序列上对所有位置两两计算相似度，对相似度进行softmax归一化得到注意力权重，最后用权重对V进行加权求和，得到每个位置关注全局信息后的输出。
- Transformer Encoder/Decoder 的结构：Encoder用自注意力理解整个输入序列，用掩码自注意力 + 交叉注意力生成输出序列
- 位置编码的作用：用 sin/cos 给每个位置加唯一标识，让模型知道顺序。
